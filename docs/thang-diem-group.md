# Thang chấm group (100 điểm) — giống tab Chấm group trên Smock Radar

**Cổng loại thẳng** (`gates` = true nếu trượt một cổng; khi đó tier = "Loại"): nội quy cấm promotion/business/selling · dưới 1 bài mới trong 14 ngày · chủ yếu không phải tiếng Anh, hoặc chuyên đồ cũ/đồ lạ · đã bị admin gỡ bài (thông tin trong inbox nếu có).

| Khoá | Tiêu chí | Điểm |
| --- | --- | --- |
| icp | Đúng tệp: smocked/đồ trẻ em/boutique/wholesale = 25 · đồ trẻ em chung = 15 · thời trang chung = 5 · không liên quan = 0 | 0–25 |
| sell | Nội quy ghi rõ wholesale/for sale = 20 · không nói gì = 10 · hạn chế = 0 | 0–20 |
| active | Bài mới/ngày trong 7 ngày: ≥5 = 15 · 1–4 = 8 · <1 = 2 | 2–15 |
| engage | Trung vị (cảm xúc+comment) 20 bài: ≥10 = 15 · 3–9 = 8 · <3 = 2 | 2–15 |
| buyer | Tỷ lệ bài "ISO / looking for / need supplier": ≥20% = 10 · 5–19% = 5 · 0 = 0 | 0–10 |
| geo | Chủ yếu US/EU = 10 · lẫn = 5 · khác = 0 | 0–10 |
| spam | <20% bài spam/trùng = 5 · nhiều rác = 0 | 0–5 |

`total` = tổng 7 khoá. Tier: A ≥ 75 · B 50–74 · C 30–49 · Loại < 30 hoặc trượt cổng.
`evidence`: mỗi khoá một câu ngắn trích từ file text (ví dụ "nội quy dòng 3: 'No selling'"; "đếm 6/20 bài ISO").
